# Reporte de Bug: Falta Extracción de JWT — Hardcoded userID=1, roleID=1

**Tipo**: Implementation drift + Security flaw

**Severidad**: 🔴 Critical

**Feature**: 009-inventario-conteo

**Reportado**: 2026-07-13

**Status: ✅ Patched

**Patched**: 2026-07-13

---

## Descripción

El backend hardcodea `userID := int64(1)` y `roleID := int64(1)` en **todos los endpoints**. No se extrae la identidad real desde el JWT token.

**Impacto de Seguridad**:

- ❌ **Cualquier usuario autenticado actúa como usuario 1 con rol 1**

- ❌ Las validaciones de RBAC (lider_tienda solo su tienda, barista sin acceso histórico) son ignoradas

- ❌ Auditoría imposible (todos los conteos parecen ser del usuario 1)

**Log Backend Evidence**:

```text

inventario.iniciar.post: iniciando tienda_id=1 tipo=diario horario=0x1e10f3268890

```text

No hay `user_id` ni `rol` en los logs → no se están extrayendo.

## Solución Recomendada

### Paso 1: Crear Helper en Handler (Optional, pero Clean)

En `handler.go` agregar:

```go
// ExtractUserClaims extrae datos del JWT desde contexto
func (h *Handler) ExtractUserClaims(r *http.Request) (*auth.Claims, error) {
  claims := auth.ClaimsFromContext(r.Context())
  if claims == nil {
    return nil, NewError("unauthorized", "Token JWT requerido")
  }
  return claims, nil
}

```text
