## Descripción

**La fórmula central de la feature NO está implementada.** Según RF-INV-02.2, el `valor_sugerido` debe calcularse como:

```text

valor_sugerido = stock_inventario_referencia + compras_periodo − ventas_periodo − mermas_periodo

```text

Pero el código **nunca ejecuta este cálculo**. Los valores se copian directamente de la BD sin procesamiento.

## Trazabilidad

### spec.md

**RF-INV-02.2** (línea 160-178) — **Requisito Core**:

> "El valor sugerido de cada item se calcula con la siguiente fórmula:
> `valor_sugerido = stock_inventario_referencia + compras_periodo − ventas_periodo − mermas_periodo`
> Donde:
> - `stock_inventario_referencia`: valor real contado en el inventario completado más reciente
> - `compras_periodo`: unidades recibidas por recepciones de pedido y compras de caja menor
> - `ventas_periodo`: unidades descontadas por ventas procesadas
> - `mermas_periodo`: unidades registradas como merma

Esta es la **base lógica de toda la feature**. Sin ella, el conteo es inútil (no hay base confiable de qué debería ser el stock).

## Solución Recomendada

### Paso 1: Crear Método en Service para Calcular Valor Sugerido

En `service.go`:

```go
func (s *Service) calcularValorSugerido(ctx context.Context,
  tiendaID, itemID int64, tipo Tipo, fecha time.Time) (float64, error) {

  // 1. Obtener stock de referencia (inventario completado más reciente)
  refInv, refValor, err := s.repository.GetStockReferenciaByTipo(ctx, tiendaID, tipo, itemID)
  if err != nil {
    return 0, err  // O usar 0 si es el primer conteo (inicial)
  }

  // 2. Calcular períodos (desde referencia hasta ahora)
  if refInv == nil {
    // Primer conteo o inicial: valor_sugerido = 0
    return 0, nil
  }

  desdeRef := refInv.CompletadoEn
  hastaAhora := time.Now()

  // 3. Sumar movimientos en período
  compras, _ := s.repository.SumarComprasPeriodo(ctx, tiendaID, desdeRef, hastaAhora, itemID)
  ventas, _ := s.repository.SumarVentasPeriodo(ctx, tiendaID, desdeRef, hastaAhora, itemID)
  mermas, _ := s.repository.SumarMermasPeriodo(ctx, tiendaID, desdeRef, hastaAhora, itemID)

  // 4. Aplicar fórmula RF-INV-02.2
  valorSugerido := refValor + compras - ventas - mermas

  return valorSugerido, nil
}

```text

### Paso 2: Actualizar Iniciar para Usar el Cálculo

En `service.go` línea 67-126:

```go
func (s *Service) Iniciar(...) {
  // ... obtenidas items

  for _, item := range items {
    // ✅ Calcular valor_sugerido per RF-INV-02.2
    valorSugerido, err := s.calcularValorSugerido(ctx, req.TiendaID, item.ID, req.Tipo, time.Now())
    if err != nil {

      s.logger.WarnContext(ctx, "error calculando valor sugerido", "item_id", item.ID, "error", err)

      ItemID: item.ID,

      ValorEsperado: valorSugerido,  // Inicialmente, esperado = sugerido

  // Inserta con valores calculados
  err := s.repository.CreateDetalleInventario(ctx, detalles)
}

```text
