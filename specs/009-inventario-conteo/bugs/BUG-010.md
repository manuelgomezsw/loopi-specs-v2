**Tipo**: Implementation drift

**Severidad**: 🟠 High

**Reportado**: 2026-07-13

**Status: ✅ Patched

**Patched**: 2026-07-13

## Descripción

CLAUDE.md [BE-OBS-01] ordena que **todos los logs deben incluir campos obligatorios**:

- `tienda_id`

- `user_id`

- `rol`

- `timestamp` (automático en slog)

- `operación`

- `nivel` (Info, Warn, Error)

Los logs actuales **omiten usuario, rol y tienda_id**, imposibilitando trazabilidad.

**Ejemplo Actual** (handler.go línea 42-44):

```go
h.logger.InfoContext(ctx, "inventario.sugerencia.get: success",
  "tipo", sugerencia.Tipo,
  "horario", sugerencia.Horario)
  // ❌ Falta: user_id, rol, tienda_id

```text

**Ejemplo Esperado** (según CLAUDE.md):

```go
h.logger.InfoContext(ctx, "inventario.sugerencia.get: success",
  "user_id", claims.UserID,
  "rol", claims.RoleID,
  "tienda_id", 1,  // O claims.TiendaID si aplica
  "tipo", sugerencia.Tipo,
  "horario", sugerencia.Horario)

```text

## Solución

### Paso 1: Agregar Helper para Logs Estructurados

En `handler.go` agregar:

```go
func (h *Handler) logOperation(ctx context.Context,
  level slog.Level,
  operation string,
  userID, roleID, tiendaID int64,
  attrs ...any) {

  allAttrs := []any{
    "user_id", userID,
    "rol", roleID,
    "tienda_id", tiendaID,
  }
  allAttrs = append(allAttrs, attrs...)

  h.logger.LogContext(ctx, level, operation, allAttrs...)
}

```text

### Paso 2: Usar en Cada Endpoint

Reemplazar:

```go
h.logger.InfoContext(ctx, "inventario.sugerencia.get: success",
  "tipo", sugerencia.Tipo,
  "horario", sugerencia.Horario)

```text

Con:

```go
h.logOperation(ctx, slog.LevelInfo, "inventario.sugerencia.get: success",
  claims.UserID, claims.RoleID, 1,
  "tipo", sugerencia.Tipo,
  "horario", sugerencia.Horario)

```text

### Paso 3: Agregar Logs de Error con Context

En bloques de error:

```go
if err != nil {
  h.logOperation(ctx, slog.LevelError, "inventario.iniciar.post: error",
    claims.UserID, claims.RoleID, req.TiendaID,
    "error", err.Error(),
    "error_code", "INIT_FAILED")
  h.respondError(w, http.StatusBadRequest, "error", err.Error())
  return
}

```text
