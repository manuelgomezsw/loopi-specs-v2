# BUG-014: Errores de Iniciar Conteo No Se Visualizan en UI

**Type**: Implementation drift  
**Severity**: High  
**Feature**: 009-inventario-conteo  
**Reported**: 2026-07-18  
**Discoverer**: Manuel Gomez  

## Descripción

Cuando un usuario intenta iniciar un conteo y ya existe uno en progreso (error 409 `conteo_duplicado`):

**Backend**: Retorna correctamente HTTP 409 con mensaje claro:

```json
{
  "error_code": "conteo_duplicado",
  "error_message": "Ya existe un conteo en progreso para esta tienda, tipo y horario en esta fecha"
}
```

**Frontend**: No muestra nada al usuario

- Error se loguea solo en consola: `console.error('Error al iniciar conteo:', err)`
- No hay feedback visual
- Usuario no sabe por qué falló
- UI quedó en estado "select" sin indicación de problema

**Logs Capturados**:

Backend:

```text
ERROR inventario.iniciar: error creando tienda_id=1 error="Ya existe un conteo en progreso..."
WARN inventario.iniciar.post: error error_code=conteo_duplicado error_message="..." tienda_id=1
```

Frontend:

```text
:4200/api/v1/inventarios:1  Failed to load resource: 409 (Conflict)
Error al iniciar conteo: HttpErrorResponse
```

## Recommended Fix

### Frontend Component (inventario-conteo.component.ts)

**1. Agregar variable de estado** (línea 42):

```typescript
iniciarConteoError = '';
iniciarConteoLoading = false;
```

**2. Actualizar handler de error** (línea 163-169):

```typescript
iniciarConteo(): void {
  if (!this.formulario.valid) return;

  this.iniciarConteoLoading = true;
  this.iniciarConteoError = '';

  const formValue = this.formulario.value;
  this.inventarioService.iniciarConteo({
    tienda_id: this.formData.tienda_id,
    tipo: formValue.tipo,
    horario: formValue.horario || undefined
  })
    .pipe(takeUntil(this.destroy$))
    .subscribe({
      next: (data) => {
        this.inventarioActual = data;
        this.step = 'register';
        this.iniciarConteoLoading = false;
      },
      error: (err) => {
        this.iniciarConteoLoading = false;
        const errorMsg = err.error?.error_message || 'No se pudo iniciar el conteo. Intenta de nuevo.';
        this.iniciarConteoError = errorMsg;
        console.error('Error al iniciar conteo:', err);
      }
    });
}
```

### Frontend Template (inventario-conteo.component.html)

**Agregar sección de error de iniciar conteo** (después de sugerencia, antes de botones - línea 76-77):

```html
<!-- Error al iniciar conteo -->
@if (iniciarConteoError) {
  <div class="p-4 bg-red-50 border border-red-200 rounded-lg">
    <p class="text-sm text-red-900">❌ {{ iniciarConteoError }}</p>
  </div>
}

<!-- Botones -->
<div class="flex gap-3">
  <button
    type="submit"
    [disabled]="formulario.invalid || iniciarConteoLoading"
    class="flex-1 px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 disabled:bg-gray-300 disabled:cursor-not-allowed transition-colors font-medium"
  >
    @if (iniciarConteoLoading) {
      <span class="inline-block animate-spin h-4 w-4 border-2 border-white border-t-transparent rounded-full mr-2"></span>
      Iniciando...
    } @else {
      Iniciar Conteo
    }
  </button>
</div>
```
