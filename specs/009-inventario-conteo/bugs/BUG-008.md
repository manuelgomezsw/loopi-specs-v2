## Solución Recomendada

### Paso 1: Definir Constantes de Rol

En `models.go`:

```go
const (
  RoleAdmin       = "admin"
  RoleLiderTienda = "lider_tienda"
  RoleBarista     = "barista"
)

```text

### Paso 2: Implementar Validaciones en Service

En `service.go`, actualizar cada método:

**Iniciar (línea 67-109)**:

```go
func (s *Service) Iniciar(ctx context.Context, req *CreateInventarioReq, userID, roleID int64) (*InventarioResp, error) {
  // ✅ VALIDACIÓN RBAC: lider_tienda y barista solo su tienda
  claims := /* extraer del context o pasar como param */
  if roleID != RoleAdmin && claims.TiendaID != req.TiendaID {
    return nil, NewError("sin_permiso", "Solo puede crear conteos en su tienda")
  }
  // ... resto de lógica
}

```text

**Listar (línea 291-314)**:

```go
func (s *Service) Listar(ctx context.Context, filtros *FiltrosInventario, userID, roleID int64) {
  // ✅ Validar acceso según rol
  if roleID == RoleBarista {
    return nil, NewError("sin_permiso", "Barista no puede ver historial")
  }

  if roleID == RoleLiderTienda {
    // Forzar filtro a su tienda
    filtros.TiendaID = claims.TiendaID  // Garantizar que solo ve su tienda
  }
  // Si admin, permitir cualquier filtro
}

```text

### Paso 3: Agregar Helper para Validación de Responsable

```go
func (s *Service) validateResponsable(ctx context.Context, inventarioID, userID int64) error {
  inv, err := s.repository.GetInventario(ctx, inventarioID)
  if err != nil {
    return err
  }

  if inv.ResponsableID != userID {
    return NewError("conteo_bloqueado", "Solo el responsable puede registrar valores")
  }
  return nil
}

```text
