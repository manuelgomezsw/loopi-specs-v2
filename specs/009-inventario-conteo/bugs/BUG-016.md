# BUG-016: Items No Se Crean Automáticamente en Conteo

**Type**: Implementation gap  
**Severity**: Critical  
**Feature**: 009-inventario-conteo  
**Discovered**: 2026-07-18

## Descripción del Problema

Cuando se ejecuta `POST /api/v1/inventarios` para iniciar un conteo, el flujo actual es:

```text
1. Service.Iniciar()
   ├── repo.CreateInventario() → inserta en tabla inventarios ✓
   └── repo.GetInventarioDetalle() → query desde detalle_inventario
       └── RESULTADO: retorna 0 items (tabla detalle_inventario vacía) ❌
```

### Root Cause

Las funciones que deberían crear los items **están definidas pero NUNCA se llaman**:

1. **`CreateDetalleInventario()`** (repository.go:111)
   - Propósito: Insertar registros en `detalle_inventario` para cada item
   - Uso: 0 llamadas en todo el codebase

2. **`SnapshotStockActual()`** (repository.go:501)
   - Propósito: Tomar snapshot de stock en `stock_actual` al iniciar
   - Uso: 0 llamadas en servicio (solo en tests/mocks)


## Preguntas Abiertas

1. **¿De dónde obtiene los items?**
   - **Actual**: Intenta traer de `detalle_inventario` (vacío) → 0 items
   - **Debería**: De tabla `items` (con filtros: activos, tienda, frecuencia)

2. **¿Dónde viene `valor_sugerido`?**
   - **Actual**: No existe mecanismo
   - **Debería**: De `stock_actual.valor_snapshot` o default a 0

3. **¿Quién crea los registros en `detalle_inventario`?**
   - **Actual**: No se crean (GAP)
   - **Debería**: Service.Iniciar() → repo.CreateDetalleInventario()

4. **¿Se toma snapshot automáticamente?**
   - **Actual**: No (función existe pero no se llama)
   - **Debería**: Service.Iniciar() → repo.SnapshotStockActual()

## Impacto en Testing

El test script `test_inventario_conteo.sql` que creamos:


**NO funcionará** con el flujo actual porque:

2. Pero cuando inicia conteo, busca en `detalle_inventario` ❌
3. Y `detalle_inventario` no tiene los items porque no se crean automáticamente ❌

**Resultado**: GET /inventarios/{id} retorna 0 items

```go
func (s *ServiceImpl) Iniciar(ctx context.Context, req *CreateInventarioReq, userID int64, role string, userTiendaID *int64) (*InventarioResp, error) {
    // ... validaciones existentes ...
    
    // Crear inventario
    createdInv, err := s.repo.CreateInventario(ctx, inv)
    if err != nil {
        return nil, err
    }
    
    // NUEVO: Obtener todos los items activos de la tienda
    // Filtros: activo=1, frecuencia_inventario=tipo (o todo)
    itemsActivos, err := s.repo.GetItemsActivosTienda(ctx, req.TiendaID)
    if err != nil {
        return nil, err
    }
    
    // NUEVO: Crear detalles para cada item
    detalles := make([]DetalleInventario, len(itemsActivos))
    itemIDs := make([]int64, len(itemsActivos))
    for i, item := range itemsActivos {
        detalles[i] = DetalleInventario{
            InventarioID: createdInv.ID,
            ItemID:       item.ID,
            ValorSugerido: 0, // O desde stock_actual
            ValorEsperado: 0,
        }
        itemIDs[i] = item.ID
    }
    
    err = s.repo.CreateDetalleInventario(ctx, detalles)
    if err != nil {
        return nil, err
    }
    
    // NUEVO: Tomar snapshot de stock actual
    err = s.repo.SnapshotStockActual(ctx, createdInv, itemIDs)
    if err != nil {
        s.logger.WarnContext(ctx, "inventario.iniciar: error tomando snapshot",
            "inventario_id", createdInv.ID)
        // No bloquear por RD-04 (requirement: snapshot es optional)
    }
    
    // Obtener detalles con valores sugeridos
    createdInv, err = s.repo.GetInventarioDetalle(ctx, createdInv.ID)
    if err != nil {
        return nil, err
    }
    
    return s.mapInventarioToResp(createdInv), nil
```

### Repository (repository.go - método nuevo)

```go
// GetItemsActivosTienda obtiene todos los items activos de una tienda
func (r *RepositoryImpl) GetItemsActivosTienda(ctx context.Context, tiendaID int64) ([]*Item, error) {
    query := `
        SELECT id, codigo, nombre, tipo, frecuencia_inventario, stock_seguridad, activo
        FROM items
        WHERE activo = 1
        ORDER BY id
    `
    
    rows, err := r.db.QueryContext(ctx, query)
    if err != nil {
        return nil, fmt.Errorf("error obteniendo items activos: %w", err)
    }
    defer rows.Close()
    
    items := []*Item{}
    for rows.Next() {
        item := &Item{}
        err := rows.Scan(
            &item.ID, &item.Codigo, &item.Nombre, &item.Tipo,
            &item.FrecuenciaInventario, &item.StockSeguridad, &item.Activo,
        )
        if err != nil {
            return nil, fmt.Errorf("error scanneando item: %w", err)
        }
        items = append(items, item)
    }
    
    return items, rows.Err()
}
```
