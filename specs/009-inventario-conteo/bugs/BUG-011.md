## Descripción

El endpoint `GET /api/v1/inventarios?tienda_id=1&tipo=diario&pagina=2` **ignora todos los query parameters**. Hardcodea valores por defecto.

**handler.go línea 224-239** (GetHistorial):

```go
func (h *Handler) GetHistorial(w http.ResponseWriter, r *http.Request) {
  // TODO: Parsear query params para filtros

  // Hardcoding: ignora r.URL.Query()
  filtros := &FiltrosInventario{
    Pagina:      1,           // ← Siempre 1, ignora ?pagina=N
    PorPagina:   50,          // ← Siempre 50
    // TiendaID, Tipo, Estado, FechaDesde, FechaHasta: nunca se leen
  }

  // Retorna siempre página 1, sin filtros
  resp, err := h.service.Listar(ctx, filtros, userID, roleID)
}

```text

**Impacto**:

- ❌ Usuario no puede navegar a página 2, 3, etc.

- ❌ Usuario no puede filtrar por tipo=diario, estado=completado, etc.

- ❌ RF-INV-04 (Historial y Consulta) no funciona

## Solución Recomendada

### Paso 1: Crear Helper para Parsear Query Params

En `handler.go`:

```go
func (h *Handler) parseHistorialParams(r *http.Request) *FiltrosInventario {
  q := r.URL.Query()

  filtros := &FiltrosInventario{
    Pagina:    1,
    PorPagina: 50,
  }

  // Parsear tienda_id
  if tiendaID := q.Get("tienda_id"); tiendaID != "" {
    if id, err := strconv.ParseInt(tiendaID, 10, 64); err == nil {
      filtros.TiendaID = id
    }
  }

  // Parsear tipo
  if tipo := q.Get("tipo"); tipo != "" {
    tiposValidos := []string{"diario", "semanal", "mensual", "inicial"}
    for _, v := range tiposValidos {
      if tipo == v {
        filtros.Tipo = Tipo(tipo)
        break
      }
    }
  }

  // Parsear estado
  if estado := q.Get("estado"); estado != "" {
    estadosValidos := []string{"en_progreso", "completado"}
    for _, v := range estadosValidos {
      if estado == v {
        filtros.Estado = Estado(estado)
        break
      }
    }
  }

  // Parsear fechas
  if desde := q.Get("desde"); desde != "" {
    if fecha, err := time.Parse("2006-01-02", desde); err == nil {
      filtros.FechaDesde = fecha
    }
  }
  if hasta := q.Get("hasta"); hasta != "" {
    if fecha, err := time.Parse("2006-01-02", hasta); err == nil {
      filtros.FechaHasta = fecha
    }
  }

  // Parsear paginación (con validación)
  if pagina := q.Get("pagina"); pagina != "" {
    if p, err := strconv.Atoi(pagina); err == nil && p > 0 {
      filtros.Pagina = p
    }
  }
  if porPagina := q.Get("por_pagina"); porPagina != "" {
    if pp, err := strconv.Atoi(porPagina); err == nil && pp > 0 && pp <= 200 {
      filtros.PorPagina = pp
    }
  }

  return filtros
}

```text
