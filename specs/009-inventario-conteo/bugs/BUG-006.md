# Reporte de Bug: Path Values Hardcodeados — Endpoints Rotos

**Tipo**: Implementation drift

**Severidad**: 🔴 Critical

**Feature**: 009-inventario-conteo

**Reportado**: 2026-07-13

**Status: ✅ Patched

**Patched**: 2026-07-13

## Descripción

Endpoints que reciben parámetros en el path (`{id}`, `{item_id}`) tienen comentarios TODO pero hardcodean valores `1`. **Estos endpoints están completamente rotos.**

```go
// handler.go línea 139-142 (PATCH handler)
idStr := r.PathValue("id")        // No se usa
if idStr == "" {...}

inventarioID := int64(1)  // ← HARDCODED, debería ser parseado desde idStr
itemID := int64(1)        // ← HARDCODED

```text

**Endpoints afectados**:

- ❌ `PATCH /api/v1/inventarios/{id}/items/{item_id}` — Siempre actualiza item 1 en inventario 1

- ❌ `POST /api/v1/inventarios/{id}/confirmar` — Siempre confirma inventario 1

- ❌ `DELETE /api/v1/inventarios/{id}` — Siempre elimina inventario 1

- ❌ `GET /api/v1/inventarios/{id}` — Siempre obtiene inventario 1 (ver línea 139-142)

---

## Solución

Crear helper en `handler.go`:

```go
func parsePathID(r *http.Request, paramName string) (int64, error) {
  idStr := r.PathValue(paramName)
  if idStr == "" {
    return 0, fmt.Errorf("%s es requerido en path", paramName)
  }
  id, err := strconv.ParseInt(idStr, 10, 64)
  if err != nil {
    return 0, fmt.Errorf("%s debe ser número válido", paramName)
  }
  return id, nil
}

```text

Aplicar en cada endpoint:

**PatchItemValor** (línea 139-142):

```go
// Reemplazar TODO + hardcoding con:

inventarioID, err := parsePathID(r, "id")
if err != nil {
  h.respondError(w, http.StatusBadRequest, "invalid_id", err.Error())
  return
}

itemID, err := parsePathID(r, "item_id")
if err != nil {
  h.respondError(w, http.StatusBadRequest, "invalid_item_id", err.Error())
  return
}

```text

Lo mismo para PostConfirmar (línea 171-174) y DeleteInventario (línea 199-204).
