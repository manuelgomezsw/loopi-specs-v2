## Problemas Detallados

### A) Métricas Faltantes

Archivo `handler.go` línea 13-26:

```go
type Handler struct {
  service Service
  logger  *slog.Logger
  tracer  interface{} // ← Placeholder, nunca inicializado
}

```text

**Debería tener** (como Items):

```go
type Metrics struct {
  inicioDuration      prometheus.Histogram
  registroDuration    prometheus.Histogram
  confirmacionDuration prometheus.Histogram
  modificacionDuration prometheus.Histogram
  eliminacionDuration  prometheus.Histogram
  listarDuration      prometheus.Histogram

  erroresTotal        prometheus.Counter
  exitoTotal          prometheus.Counter
}

type Handler struct {
  service Service
  logger  *slog.Logger
  tracer  trace.Tracer  // ← Real tracer
  metrics Metrics       // ← Instrumentos OTel
}

```text

### E) Binding Tags Decorativos

`models.go` línea 71-74:

```go
type CreateInventarioReq struct {
  TiendaID   int64   `json:"tienda_id" binding:"required"`  // ← Tags "required"
  Tipo       Tipo    `json:"tipo" binding:"required"`       // ← Pero nunca validados
  Horario    *Horario `json:"horario"`
}

```text

El código usa `json.NewDecoder()` de stdlib que **ignora binding tags** (son para Gin). La validación real nunca ocurre:

```go
var req CreateInventarioReq
if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
  // ← Solo valida JSON syntax, no binding tags
}

```text

Si usuario envía `POST { "tipo": "" }`, el decode **no falla** (string vacío es válido JSON).

## Solución Recomendada

### 1. Agregar Métricas (Copiar de Items)

Crear en `handler.go`:

```go
type Metrics struct {
  InitDuration       prometheus.Histogram
  RegisterDuration   prometheus.Histogram
  ConfirmDuration    prometheus.Histogram
  ListDuration       prometheus.Histogram
  ErrorCount         prometheus.Counter
  SuccessCount       prometheus.Counter
}

func NewMetrics() *Metrics {
  return &Metrics{
    InitDuration: prometheus.NewHistogram(...),
    // ... etc
  }
}

```text

### 2. Instrumentar Tracer Correctamente

```go
func (h *Handler) PostInventario(w http.ResponseWriter, r *http.Request) {
  ctx := r.Context()

  // ✅ Iniciar span
  ctx, span := h.tracer.Start(ctx, "inventario.conteos.iniciar",
    trace.WithAttributes(
      attribute.String("tienda_id", fmt.Sprintf("%d", req.TiendaID)),
      attribute.String("tipo", string(req.Tipo)),
    ))
  defer span.End()

  // ... resto de lógica

  // ✅ Registrar métrica
  h.metrics.InitDuration.Observe(time.Since(start).Seconds())
  h.metrics.SuccessCount.Inc()
}

```text

### 3. Reparar Tests

- Mover `ptrHorario()` a `helper_test.go` compartido

- Corregir mock de repository

- Agregar mínimo 20+ test cases cubriendo errors

### 4. Validar con Biblioteca Explícita

En lugar de binding tags decorativos, usar `github.com/go-playground/validator/v10`:

```go
type CreateInventarioReq struct {
  TiendaID int64    `json:"tienda_id" validate:"required,gt=0"`
  Tipo     Tipo     `json:"tipo" validate:"required,oneof=diario semanal mensual inicial"`
  Horario  *Horario `json:"horario" validate:"omitempty,oneof=apertura mediodia cierre"`
}

// En handler
validate := validator.New()
if err := validate.Struct(req); err != nil {
  h.respondError(w, http.StatusBadRequest, "validation_error", err.Error())
}

```text

### 5. Usar Zona Horaria Colombia

```go
loc, _ := time.LoadLocation("America/Bogota")
now := time.Now().In(loc)
hour := now.Hour()

```text
