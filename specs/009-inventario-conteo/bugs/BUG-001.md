**Tipo**: Implementation drift

**Severidad**: Critical

**Feature**: 009-inventario-conteo

**Reportado**: 2026-07-13

**Status**: ✅ Patched

**Patched**: 2026-07-13

## Descripción

Al intentar iniciar un conteo de inventario tras seleccionar el tipo de conteo y horario, la aplicación falla con errores HTTP 404. El usuario hace clic en el botón "Iniciar conteo" pero no sucede nada, y la consola del navegador muestra:

```text
Failed to load resource: the server responded with a status of 404 (Not Found)
:4200/api/v1/inventarios/sugerencia:1  Failed to load resource: the server responded with a status of 404 (Not Found)
inventario-conteo.component.ts:63 Error al obtener sugerencia: HttpErrorResponse
:4200/api/v1/inventarios:1  Failed to load resource: the server responded with a status of 404 (Not Found)
inventario-conteo.component.ts:106 Error al iniciar conteo: HttpErrorResponse
```

El frontend envía dos solicitudes HTTP que deberían ser manejadas por el backend:

- `GET /api/v1/inventarios/sugerencia` (línea 56 de inventario.service.ts)
- `POST /api/v1/inventarios` (línea 61 de inventario.service.ts)

Ambas retornan 404, indicando que las rutas no existen en el servidor.

## Análisis de Causa Raíz

### Problema Identificado

En `/home/manuelgomezjp/repos/loopi-v2/loopi-api-v2/cmd/api/main.go`:

**Línea 75-178**: Otros módulos (tiendas, empleados, items, etc.) registran sus rutas explícitamente:

```go
// Módulo de tiendas (línea 107)
tiendasHandler.RegisterRoutes(mux, jwtMiddleware)

// Módulo de empleados (línea 121)
empleadosHandler.RegisterRoutes(mux, jwtMiddleware)

// Módulo de items (línea 178)
itemsHandler.RegisterRoutes(mux, jwtMiddleware)
```

**Resultado**: El módulo de inventarios **nunca se inicializa ni registra** en main.go. No existe:

```go
// FALTA: Inicializar módulo de inventarios
inventariosRepo := inventarios.NewRepository(db)
inventariosSvc := inventarios.NewService(inventariosRepo)
inventariosHandler := inventarios.NewHandler(inventariosSvc)
inventariosHandler.RegisterRoutes(mux, jwtMiddleware) // ← ESTA LÍNEA FALTA COMPLETAMENTE
```

### Por Qué Ocurrió

1. **Tasks 028-029**: Se completaron como "implementar handlers" sin incluir "registrar rutas en main.go"
2. **No existe método `RegisterRoutes()`**: El archivo `handler.go` define métodos individuales (`GetSugerencia`, `PostInventario`, etc.) pero **no implementa un método `RegisterRoutes()`** como hacen otros módulos
3. **Falta de validación cruzada**: La tarea de "Phase 2 Checkpoint: routing complete" no fue verificada antes de continuar a Phase 3

## Solución Recomendada

### Paso 1: Agregar `RegisterRoutes()` a handler.go

En `/home/manuelgomezjp/repos/loopi-v2/loopi-api-v2/internal/inventarios/handler.go`, agregar:

```go
import "net/http"

// RegisterRoutes registra todas las rutas del módulo de inventarios
func (h *Handler) RegisterRoutes(mux *http.ServeMux, middleware func(http.Handler) http.Handler) {
    // Sin middleware (público — revisar si se requiere autenticación)
    mux.HandleFunc("GET /api/v1/inventarios/sugerencia", h.GetSugerencia)

    // Con middleware JWT
    mux.Handle("POST /api/v1/inventarios", middleware(http.HandlerFunc(h.PostInventario)))
    mux.Handle("GET /api/v1/inventarios/{id}", middleware(http.HandlerFunc(h.GetInventario)))
    mux.Handle("PATCH /api/v1/inventarios/{id}/items/{item_id}", middleware(http.HandlerFunc(h.PatchItemValor)))
    mux.Handle("POST /api/v1/inventarios/{id}/confirmar", middleware(http.HandlerFunc(h.PostConfirmar)))
    mux.Handle("DELETE /api/v1/inventarios/{id}", middleware(http.HandlerFunc(h.DeleteInventario)))
    mux.Handle("GET /api/v1/inventarios", middleware(http.HandlerFunc(h.GetHistorial)))
}
```

### Paso 2: Inicializar y registrar en main.go

En `/home/manuelgomezjp/repos/loopi-v2/loopi-api-v2/cmd/api/main.go`, después de la sección de items (antes de jobs, línea 181):

```go
// Módulo de inventarios.
inventariosRepo := inventarios.NewRepository(db)
inventariosSvc := inventarios.NewService(inventariosRepo)
inventariosHandler := inventarios.NewHandler(inventariosSvc)
inventariosHandler.RegisterRoutes(mux, jwtMiddleware)
```
