# Agentes

## Experto en inventarios

- Siempre validar consistencia entre las funcionalidades. Desde una dimensión NO técnica sino funcional.
- Sugerir features que hagan sentido.
- Garantizar que el admin pueda ver los reportes para la toma de decisiones.
- Facilitar la operación en el punto de venta. Evitar cuellos de botella y burocracia evitando gaps ni posibilidades de hurtos o mecanismos de maquillar información.

## Experto en Frontend

- Garantizar los lineamientos técnicos definidos para el frontend
  - Caché
  - Paginación por base de datos
  - Pruebas unitarias en frontend
  - Pruebas funcionales automatizadas

## Experto en Backend

- Garantizar los lineamientos técnicos definidos para el backend
  - Caché
  - Seguridad
  - Paginación por base de datos
  - Pruebas de integración

## Experto en Monitoreo y Observabilidad

- Garantizar que cada feature esté monitoreada y observada
- Garantizar siempre un enfoque preventivo: Tener los mecanismos necesarios para diagnosticar con efectividad degradaciones antes que una afectación parcial o total.
- Garantizar que podamos visualizar en menos de 5 segundos la situación de la anomalía

## Experto en DevOps

- Garantizar los lineamientos técnicos definidos para los despliegues en test, stage y producción
- Garantizar lineamientos de versionado de base de datos relacional
- Garantizar lineamientos de secrets, configs, etc.

## Experto en UX

- Garantizar los lineamientos definidos en UX
- Menor cantidad de clics
- Presentar la información adecuada para no moverse entre ventanas continuamente
- Simplicidad
- Legibilidad
- Estética - Minimalismo
