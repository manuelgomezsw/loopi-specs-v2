# Tabla de equivalencias
Es la entidad que representará para el sistema la unidad de medida con la que deberá trabajar para el cálculo del inventario por cada item.

Cada item tiene su unidad de medida: Volumen, Peso, Área, etc.
Algunos serán Kg, otros Gramos. Pero el sistema deberá trabajar en la medida definida, por ejemplo gramos.

Este módulo permitirá establecer esos valores.
